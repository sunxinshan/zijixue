# 二、Subtopic 1：比较级句型

## 学习目标

学生理解：

- 什么是比较级
- 什么情况下使用比较级
- 比较级通常用于两个对象之间的比较
- 比较级后面通常使用 `than`
- `Which ... A or B?` 可以用于询问两个对象中哪个更……
- 比较级的基本句型

## 核心规则

比较级用于比较两个对象。

例如：

`Tom is taller than Ken.`

意思是：

Tom 比 Ken 高。

`I run faster than Misa.`

意思是：

我跑得比 Misa 快。

比较级通常由形容词/副词变化后构成。

例如：

- tall → taller
- fast → faster

比较级后面如果明确说明比较对象，通常使用 `than`。

基本结构：

`A + be + 比较级 + than + B`

或：

`A + 动词 + 比较级 + than + B`

## Which 比较句

当想问“A 和 B 哪一个更……”时，可以使用：

`Which is + 比较级, A or B?`

例如：

`Which is longer, April or May?`

意思是：

四月和五月，哪个更长？

这里的 `Which` 表示“哪一个”。

## 必须覆盖的 Pattern

- 普通比较级 + than
- be 动词 + 比较级
- 行为动词 + 比较级
- Which + 比较级 + A or B

# 三、Subtopic 2：最高级句型

## 学习目标

学生理解：

- 最高级用于三个或三个以上对象之间的比较
- 最高级表达“最……”
- 最高级通常使用 `the`
- 表示比较范围时可以使用 `of` 或 `in`
- `Which ... is the + 最高级?` 可以询问“哪一个最……”

## 核心规则

当比较三个或三个以上对象时，可以使用最高级。

例如：

`Tom is the tallest of the three.`

意思是：

Tom 是三个人中最高的。

`I run the fastest in my class.`

意思是：

我在班上跑得最快。

最高级通常使用：

`the + 最高级`

如果表示多个相同类型对象中的一个，可以使用：

`the + 最高级 + of + 数量/复数对象`

例如：

`the tallest of the three`

如果表示地点、班级、家庭等范围，可以使用：

`the + 最高级 + in + 范围`

例如：

`the fastest in my class`

## Which 最高级

询问“三个或更多对象中哪个最……”时，可以使用：

`Which + 名词 + is + the + 最高级?`

例如：

`Which animal is the strongest?`

## of 和 in

`of` 通常用于表示多个对象/数量中的比较。

例如：

- of the three
- of the five
- of all

`in` 通常用于表示地点、范围、群体。

例如：

- in China
- in my family
- in my class

## 必须覆盖的 Pattern

- the + 最高级
- 最高级 + of
- 最高级 + in
- Which + 名词 + is + the + 最高级

# 四、Subtopic 3：比较级/最高级变化

这是一个需要较多练习量的 Subtopic。

不能只告诉学生“加 er / est”。

必须完整覆盖以下规则。

## Pattern 1：普通变化

一般较短的形容词/副词：

- tall → taller → tallest
- fast → faster → fastest
- long → longer → longest

比较级通常加 `-er`。

最高级通常加 `-est`。

---

## Pattern 2：e 结尾

以 `e` 结尾的单词，只需要加：

- `r`
- `st`

例如：

`large → larger → largest`

不要生成：

`largeer`

---

## Pattern 3：辅音 + y 结尾

例如：

- busy → busier → busiest
- easy → easier → easiest
- early → earlier → earliest
- happy → happier → happiest

变化规则：

词尾 `y` 改成 `i`，再加：

- `er`
- `est`

这是一个需要重点练习的 Pattern。

---

## Pattern 4：双写最后一个字母

例如：

- big → bigger → biggest
- hot → hotter → hottest

变化规则：

双写最后一个辅音字母，再加：

- `er`
- `est`

这是另一个需要重点练习的 Pattern。

---

## Pattern 5：more / most

有些较长的词不使用 `-er / -est`。

例如：

- popular → more popular → most popular
- useful → more useful → most useful
- famous → more famous → most famous
- difficult → more difficult → most difficult
- important → more important → most important
- interesting → more interesting → most interesting
- beautiful → more beautiful → most beautiful
- expensive → more expensive → most expensive
- slowly → more slowly → most slowly
- quickly → more quickly → most quickly

必须明确告诉学生：

这些词本身不通过直接加 `-er / -est` 构成比较级和最高级。

例如：

`popular → more popular`

不是：

`popularer`

`difficult → more difficult`

不是：

`difficulter`

同时要提醒：

一般的短词仍然使用 `-er / -est`。

例如：

`tall → taller → tallest`

而不是：

`more tall`

---

## Pattern 6：不规则变化

必须单独列出来，并且必须有专门练习。

教材中明确出现：

- good → better → best
- well → better → best
- many → more → most
- much → more → most

教材页底还明确提到：

- bad → worse → worst
- little → less → least

这些不能按照普通 `-er / -est` 规则推导。

例如：

`good → gooder` 是错误的。

# 五、Subtopic 4：特殊比较句型

## Pattern 1：as ... as

表示“和……一样……”。

结构：

`as + 形容词/副词原级 + as`

例如：

`My dog is as big as yours.`

意思：

我的狗和你的狗一样大。

注意：

`as ... as` 中间使用原级，不使用比较级。

错误：

`as bigger as`

---

## Pattern 2：not as ... as

表示“没有……那么……”。

结构：

`not as + 形容词/副词原级 + as`

例如：

`I'm not as tall as Penny.`

意思：

我没有 Penny 那么高。

注意：

否定形式是：

`not as ... as`

# 六、Pattern 与练习量

不能把每个 Subtopic 固定成 15 道题。

15 只是首次实现时的一个默认值，不能成为硬规则。

真正的教学单位应该是：

```text
Knowledge
 ↓
Subtopic
 ↓
Pattern
 ↓
Question
```

第一次学习：

- 每个必须覆盖的 Pattern 至少出现 1～2 题
- 重点 Pattern 可以出现更多题
- 不同 Pattern 可以有不同题量

后续强化：

- 只针对薄弱 Pattern 生成少量题目
- 默认 3～5 题即可
- 不再强制 15 题

尤其：

- y-ending
- double-consonant
- more/most
- irregular

应该允许比普通规则获得更多练习。

# 八、第一次题目生成后的缓存

新增公共 Question Pool。

第一次没有缓存题目时：

```text
Agent
 ↓
生成第一批题目
 ↓
验证题目
 ↓
保存到 Question Pool
 ↓
返回给用户
```

后续新用户第一次进入同一个 Subtopic：

```text
检查 Question Pool
 ↓
存在可用题目
 ↓
直接取缓存题
 ↓
无需再次调用 LLM
```

缓存应该属于：

`Knowledge + Subtopic + Pattern`

而不是属于某个用户。

例如：

```text
comparative
  └── comparative-formation
       ├── regular
       ├── e-ending
       ├── y-ending
       ├── double-consonant
       ├── more-most
       └── irregular
```

公共题库解决首次学习的基础题；已有用户的个性化强化仍由 Agent 决定。

---

# 九、缓存题目的安全要求

公共题目保存前必须经过 Question Validator。

至少检查：

- JSON schema 正确
- question type 正确
- answer 存在
- options 数量正确
- 无重复选项
- 当前 Knowledge 范围正确
- 当前 Subtopic 范围正确
- Pattern 合法
- 题目没有超出当前教材知识范围
- 解释内容正确
- 不允许出现当前 MVP 不支持的开放式题型

如果缓存题目被发现错误：

```text
标记 invalid
→ 不再提供给用户
→ 后续重新生成替代题
```
