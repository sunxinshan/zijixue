# 英语森林 English Forest

## 产品需求文档 PRD V0.1

**项目状态：** MVP 设计阶段\
**核心验证目标：** 把一份传统英语学习资料转化为"知识 → 练习 → 反馈 →
掌握 → 复习"的互动学习闭环。

## 1. 产品定位

英语森林是一款面向小学阶段学生的游戏化英语学习 Web 应用。

核心不是把纸质教材简单电子化，而是把学习资料中的知识点、例词、例句和练习题组织成可以互动学习、实时反馈和持续复习的内容。

## 2. MVP 核心闭环

``` text
选择知识点
  ↓
学习知识
  ↓
开始挑战
  ↓
完成一轮练习
  ↓
即时反馈
  ↓
更新知识点掌握度
  ↓
记录错题
  ↓
后续重新练习
```

## 3. MVP 第一批真实内容

第一版使用当前资料中的"比较级和最高级"作为 Demo。

内容来源包括两部分：

-   知识讲解页：比较级、最高级的规则及例词。
-   基础练习页：比较级/最高级填空，以及中译英句子练习。

第一版不依赖尚未取得的上海版四年级课本。

## 4. MVP 页面

1.  首页
2.  知识点页面
3.  学习页面
4.  闯关页面
5.  结果页面

## 5. MVP 题型

第一版：

-   选择题
-   填空题
-   句子应用题

后续：

-   拖拽排序
-   单词拼图
-   听力题
-   图片选择
-   配对
-   语音回答

## 6. 学习数据

系统需要区分：

``` text
学习资料
  ↓
知识点
  ↓
题目
  ↓
用户作答记录
  ↓
知识点掌握度
```

知识点是学习分析的核心单位，题目只是检测知识点掌握情况的一种方式。

## 7. MVP 掌握度

每个知识点保存独立的学习状态。

建议至少记录：

-   mastery
-   correctCount
-   wrongCount
-   lastPracticedAt
-   lastCorrectAt
-   streak

前端可以把掌握度展示为：

-   🌱 初学
-   🌿 学习中
-   🌳 基本掌握
-   🌲 熟练掌握

具体计算规则放在 TECH.md 中统一定义。

## 8. MVP 奖励

-   正确答题：XP
-   完成挑战：XP
-   挑战表现：星星
-   连续答对：额外奖励

奖励用于增强反馈和学习动力，不替代学习目标。

## 9. MVP 明确不做

-   登录
-   家长账号
-   云端同步
-   数据库
-   社交
-   排行榜
-   AI 聊天
-   AI 自动出题
-   OCR/拍照导入
-   复杂 3D 游戏
-   支付

## 10. 第二阶段方向

未来增加：

``` text
拍照资料
  ↓
OCR / AI 识别
  ↓
提取知识点
  ↓
生成结构化学习内容
  ↓
人工确认
  ↓
生成互动练习
```

最终目标是让用户可以把自己的英语资料变成可玩的学习内容。
