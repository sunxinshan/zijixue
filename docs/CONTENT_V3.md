# 一、Knowledge

```text
knowledgeId: comparative
name: 比较级
```

## Knowledge 学习目标

学生最终需要能够：

1. 理解“比较级”表达的是两个对象之间“一个比另一个更……”。
2. 理解并使用 `-er` 形式的基本比较级。
3. 理解比较级后使用 `than` 引出比较对象。
4. 掌握 `be + 比较级 + than`。
5. 掌握“行为动词 + 比较级 + than”。
6. 理解并使用 `Which ... A or B?` 询问两者中哪一个更……。
7. 理解三个及以上对象的“最高级”。
8. 掌握 `the + 最高级`。
9. 理解最高级后 `of / in` 的基本区别。
10. 掌握 `Which ... the + 最高级?`。
11. 掌握常见比较级、最高级变化规则。
12. 掌握 `e` 结尾单词的变化。
13. 掌握 `y` 结尾单词的变化。
14. 掌握短元音 + 单辅音结尾时双写辅音的变化。
15. 掌握常见不规则变化。
16. 掌握使用 `more / most` 的常见单词。
17. 理解 `as ... as` 表示“和……一样……”。
18. 理解 `not as ... as` 表示“没有……那么……”。
19. 能综合判断比较级、最高级、同级比较的使用场景。

# 三、Subtopic 1：普通比较级

```text
id: comparative-basic
name: 普通比较级
```

## 学习目标

学生能够理解：

> 当比较两个对象，并表达“一个比另一个更……”时，需要使用比较级。

并能够理解和使用：

```text
A + 比较级 + than + B
```

以及：

```text
Which + be + 比较级, A or B?
```

---

## Pattern 1：什么是比较级

### 核心概念

比较两个对象时，如果想表达“更高、更快、更长”等意思，需要使用比较级。

```text
tall → taller
fast → faster
long → longer
```

例如：

```text
Tom is taller than Ken.
```

意思：

> Tom 比 Ken 高。

### 教学重点

学生必须理解：

```text
tall = 高
taller = 更高
```

而不是把 `taller` 当成一个完全独立的新单词。

---

## Pattern 2：普通词的比较级加 -er

常见短词直接在词尾加 `-er`：

```text
tall → taller
fast → faster
long → longer
```

### 教学重点

让学生建立：

```text
原级 → 比较级
```

的关系。

不要只要求机械记忆。

---

## Pattern 3：比较级 + than

### 基本结构

```text
A + 比较级 + than + B
```

### 教材例子

```text
Tom is taller than Ken.
I run faster than Misa.
```

### 解释

```text
taller = 更高
than Ken = 比 Ken

faster = 更快
than Misa = 比 Misa
```

### 核心认知

`than` 用来引出比较对象。

---

## Pattern 4：be + 比较级 + than

结构：

```text
A + be + comparative + than + B
```

例子：

```text
Tom is taller than Ken.
My dog is bigger than yours.
```

学生需要知道：

- `is` 是 be 动词。
- `taller / bigger` 才是比较级。
- `than` 后面是比较对象。

---

## Pattern 5：行为动词 + 比较级 + than

比较级也可以出现在行为动词后面。

结构：

```text
A + verb + comparative + than + B
```

例子：

```text
I run faster than Misa.
She sings better than Tom.
```

重点：

```text
run + faster
sing + better
```

比较的是“跑得快不快”“唱得好不好”。

---

## Pattern 6：Which ... A or B

### 用途

当要询问两个对象中哪一个更……时：

```text
Which ... A or B?
```

教材例子：

```text
Which is longer, April or May?
```

意思：

> 四月和五月，哪个更长？

### 学生需要理解

```text
Which = 哪一个
longer = 更长
April or May = 两个比较对象
```

---

## 常见错误

1. 忘记使用比较级。
2. 把 `tall` 和 `taller` 混淆。
3. 忘记 `than`。
4. 把 `than` 后面的比较对象放错。
5. 把 `Which ... A or B?` 与普通陈述句混淆。

---

# 四、Subtopic 2：最高级

```text
id: superlative-basic
name: 最高级
```

## 学习目标

学生理解：

> 比较三个或三个以上对象，并表达“其中最……”时，使用最高级。

---

## Pattern 1：什么是最高级

比较级主要用于两个对象。

最高级用于三个或三个以上对象。

例如：

```text
tall → taller → tallest
fast → faster → fastest
```

---

## Pattern 2：最高级的基本形式

常见短词：

```text
tall → tallest
fast → fastest
```

最高级通常在词尾加：

```text
-est
```

---

## Pattern 3：the + 最高级

教材强调：

```text
the + superlative
```

例如：

```text
Tom is the tallest of the three.
```

意思：

> Tom 是三个人中最高的。

再例如：

```text
I run the fastest in my class.
```

意思：

> 我在班里跑得最快。

### 教学重点

学生需要理解：

```text
the tallest
the fastest
```

是一个完整表达。

---

## Pattern 4：最高级 + of

当表示多个对象、人数或重复对象中的“最……”时，可以使用 `of`。

例如：

```text
the tallest of the three
the fastest of the five
the best of all
```

核心理解：

```text
of + 比较范围中的对象
```

---

## Pattern 5：最高级 + in

当表示地点、班级、家庭等范围时，可以使用 `in`。

例如：

```text
the fastest in my class
the tallest in China
the best in my family
```

核心理解：

```text
in + 地点 / 范围
```

---

## Pattern 6：Which + 最高级

询问“哪个最……”时：

```text
Which + noun + be + the + superlative?
```

例如：

```text
Which animal is the strongest?
```

意思：

> 哪种动物最强壮？

---

## 常见错误

1. 两个对象比较却错误使用最高级。
2. 忘记 `the`。
3. `of` 和 `in` 的范围理解混乱。
4. 把 `Which ...` 的结构当成普通比较级问句。

---

# 五、Subtopic 3：比较级和最高级的变化规则

```text
id: comparative-form-rules
name: 比较级和最高级的变化规则
```

这是一个规则型 Subtopic。

这里不应该只用“15 道题”统一处理，而应该保证所有规则 Pattern 都被覆盖。

---

## Pattern 1：普通变化

```text
long → longer → longest
tall → taller → tallest
fast → faster → fastest
```

规则：

```text
比较级 + er
最高级 + est
```

---

## Pattern 2：e 结尾

以 `e` 结尾的词，比较级和最高级直接加：

```text
r
st
```

例如：

```text
large → larger → largest
```

不要生成：

```text
largeer
largeest
```

---

## Pattern 3：辅音字母 + y

教材中的常见例子：

```text
busy → busier → busiest
easy → easier → easiest
early → earlier → earliest
happy → happier → happiest
```

规则：

```text
y → i
```

然后：

```text
-er
-est
```

例如：

```text
busy
↓
busi + er
↓
busier
```

---

## Pattern 4：双写最后一个辅音字母

例如：

```text
big → bigger → biggest
hot → hotter → hottest
```

规则：

> 符合教材所讲短词条件时，先双写最后一个辅音字母，再加 `er / est`。

重点让学生识别：

```text
big → bigger
hot → hotter
```

而不是：

```text
biger
hoter
```

---

## Pattern 5：不规则变化

教材给出的核心例子：

```text
good → better → best
well → better → best
many → more → most
much → more → most
```

另外需要允许后续内容扩展：

```text
bad → worse → worst
little → less → least
```

注意：

> 不规则变化不能强行套用 `-er / -est`。

例如：

```text
good → gooder ❌
good → better ✅
```

---

## Pattern 6：规则选择

给学生一个原级单词，让学生判断：

- 加 `er / est`
- `e` 结尾变化
- `y → i`
- 双写辅音
- 不规则
- 使用 `more / most`

这个 Pattern 很重要，因为真正掌握规则不仅是记住结果，还要知道**为什么这样变化**。

---

# 六、Subtopic 4：more / most

```text
id: comparative-more-most
name: more / most
```

## 学习目标

学生理解：

有些较长的词不能简单地加 `-er / -est`，而是使用：

```text
more + 原级
most + 原级
```

---

## Pattern 1：more + 原级

例如：

```text
popular → more popular
useful → more useful
famous → more famous
difficult → more difficult
important → more important
interesting → more interesting
beautiful → more beautiful
expensive → more expensive
```

---

## Pattern 2：most + 原级

例如：

```text
popular → most popular
useful → most useful
famous → most famous
difficult → most difficult
important → most important
interesting → most interesting
beautiful → most beautiful
expensive → most expensive
```

---

## Pattern 3：不能随意 more + -er

教材特别强调：

```text
popular
→ more popular
```

而不是：

```text
more popularer ❌
```

普通短词也不能随意写：

```text
more tall ❌
most tall ❌
```

正确：

```text
taller
tallest
```

---

## Pattern 4：more / most 与规则变化的判断

学生需要根据单词判断使用：

```text
tall → taller → tallest

popular → more popular → most popular
```

这里是非常重要的判断题型。

---

# 七、Subtopic 5：as ... as / not as ... as

```text
id: comparative-as-as
name: as ... as / not as ... as
```

## 学习目标

学生理解：

```text
as + 形容词/副词 + as
```

表示：

> 和……一样……

而：

```text
not as + 形容词/副词 + as
```

表示：

> 没有……那么……

---

## Pattern 1：as ... as

结构：

```text
A + be + as + adjective + as + B
```

例如：

```text
My dog is as big as yours.
```

意思：

> 我的狗和你的狗一样大。

---

## Pattern 2：not as ... as

结构：

```text
A + be + not as + adjective + as + B
```

例如：

```text
I'm not as tall as Penny.
```

意思：

> 我没有 Penny 那么高。

---

## Pattern 3：as ... as 中形容词保持原级

例如：

```text
as big as
as fast as
```

不能写成：

```text
as bigger as ❌
as faster as ❌
```

重点：

> `as ... as` 中使用原级，而不是比较级。

---

## Pattern 4：not 的意义

必须帮助学生区分：

```text
I am as tall as Tom.
```

= 我和 Tom 一样高。

```text
I am not as tall as Tom.
```

= 我没有 Tom 那么高。

这里 `not` 会改变整个比较关系。

不要再固定：

```text

```

```text

历史表现

```

例如：


```text

普通变化：1

```

可能 4 题就足够。

# 十七、场景挑战

当一个 Knowledge 下所有 Subtopic 完成：

```text
所有 Subtopic Mastery > 90%
        ↓
进入场景挑战赛
```

场景挑战赛：

- 混合所有 Subtopic
- 混合所有 Pattern
- 不能只考学生最擅长的部分
- 包含比较级、最高级、more/most、as...as 等
- 特殊变化必须有覆盖
- 题目数量可以少于普通学习阶段
- 重点验证综合迁移能力

如果挑战成功：

```text
Knowledge 完成
↓
场景完成
↓
角色获得形象变化
↓
解锁下一个 Knowledge
```

如果失败：

```text
分析错误
↓
定位相关 Subtopic / Pattern
↓
重新复习
↓
重新挑战
```

# 十八、内容边界

Agent 可以：

- 改写解释方式
- 调整解释长度
- 选择例子
- 生成新的例题
- 根据学生错误改变教学策略
- 调整 Pattern 练习比例

Agent 不可以：

- 修改教材规则
- 自行增加超出当前 Knowledge 的语法知识
- 把其他 Knowledge 的内容混进当前 Subtopic
- 因为自己认为某条规则“应该如此”而改变 Content
- 忽略必须覆盖的 Pattern

核心原则：

> **Content 定义“教什么”，Agent 决定“怎么教”。**
